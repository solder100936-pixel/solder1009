## 工具回傳文字（原樣）
The Game Accessibility Guidelines site lists speed and pause-related options under both motor and cognitive headings, and the search turned up a few concrete examples.

**Motor (basic level):** The guidelines suggest an option to change game speed. They also say precise timing should not be essential. Developers can offer alternatives, actions that work while paused, or a skip option. (Motor (Control / mobility) Basic - Include an option to adjust the game speed - Do not make precise timing essential to gameplay – offer alternatives, actions that can be carried out while paused, or a skip mechanism)

**Motor (rationale):** A speed setting is described as helping with timing problems, since it slows the whole game down. (Issues with precise timing can be alleviated very effectively with a choice of game speed)

**Cognitive (intermediate level):** Speed control is also recommended for players who struggle to process fast action, giving them more time to understand what is happening. (Difficulty with quickly processing action can be helped by a choice of game speed, allowing more time to work out the breadth of what is going on.)

**Text pacing:** The cognitive guidance also covers dialogue. Players should be able to move through text prompts at their own pace. A university accessibility checklist built on these guidelines adds that text should never advance automatically after a set time. (The dialog text only progresses when the player clicks. Never automatically after a certain time.)

**Motor (input):** The guidelines also advise avoiding repeated inputs such as button-mashing and quick time events. (Avoid repeated inputs (button-mashing/quick time events))

**Caveat:** I didn't find a guideline that is specifically about pause. Pause-related advice appears mainly in the precise-timing item above and in secondary commentary, such as a blog noting that offering game speed configuration and the ability to prepare actions while the game is paused are some easy ways to assist those with motor and cognitive impairments. Also, the guidelines' tiering of these items (basic vs. intermediate) varies by page, so check the current site before citing a specific level.
